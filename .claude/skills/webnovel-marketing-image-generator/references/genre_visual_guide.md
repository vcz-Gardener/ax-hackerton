# 장르별 비주얼 가이드

## 로맨스 (Romance)

### 색상 팔레트
```
주조색: #FFE5E5 (연한 핑크)
보조색: #FFB6C1 (라이트 핑크)
강조색: #FF69B4 (핫 핑크)
악센트: #FF1493 (딥 핑크)
```

### 분위기 키워드
- 몽환적 (dreamy)
- 설레는 (heart-fluttering)
- 따뜻한 (warm)
- 로맨틱한 (romantic)

### 필수 비주얼 요소
- **캐릭터 포커스**: 주인공 커플의 눈맞춤, 손잡기
- **배경**: 벚꽃, 카페, 야경, 일몰
- **소품**: 꽃다발, 반지, 편지, 커피잔
- **조명**: 부드러운 백라이트, 보케 효과

### 구도 권장사항
- 중앙 대칭 (커플을 중심으로)
- 클로즈업 (감정 표현 중시)
- 얕은 피사계 심도 (배경 흐림 효과)

## 장르 혼합 팁

### 로맨스 + 판타지
- 판타지 배경 + 로맨스 조명
- 마법 요소를 로맨틱하게 (별빛, 반딧불이)

### 스릴러 + 로맨스
- 어두운 톤 + 캐릭터 간 감정선 강조
- 긴장감 속 친밀한 순간

### 코미디 + 액션
- 역동적 구도 + 과장된 표현
- 밝은 색상 유지하며 액션 연출

## 이미지 비율별 구도 가이드

### 1:1 (인스타그램)
- 중앙 집중형 구도
- 캐릭터 바스트 샷 or 클로즈업
- 텍스트 영역: 상단 or 하단 20%

### 16:9 (유튜브)
- 좌우 공간 활용
- 텍스트 영역: 좌측 or 우측 1/3
- 캐릭터 시선 방향 고려

### 9:16 (세로형 티저)
- 수직 동선 활용
- 상-중-하 3단 구성
- 타이틀: 상단, 캐릭터: 중앙, CTA: 하단
